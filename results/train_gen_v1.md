# train 합성 1차 (폐기) 기록

- 모델: ollama gemma3:4b, 프롬프트: 양성/음성 공통 ("링크가 필요하면 가짜 URL")
- 실행 결과: LLM 호출 65회 (JSON 오류 2회), 생성 303건 → 300건 사용, train 340건 (양성 172, 음성 168)
- 문제 1 라벨 노이즈: 음성(llm_generated)의 72%에 URL 포함 (양성 93%). 예: "제안서 템플릿은 여기 있습니다: <노션 URL>"이 라벨 0
- 문제 2 누수 검사 미작동: 비교 대상 파일(label_template.csv)이 test.csv로 이름이 바뀌어 0건과 비교됨
- 문제 3 도메인 차이: 생성 문장 길이 중앙값 121자 (실제 카톡 마스킹 로그 8자), '습니다' 비율 43% (시드 10%)
- 조치: 라벨별 프롬프트 분리, 음성에 URL 있으면 버림, test.csv와 누수 검사, 10~60자 카톡 말투 지시
